# 红日靶场 (vulnstack) 学习笔记集合

> **项目简介**：本仓库为个人在攻克“红日安全”系列靶场（1-7）过程中的完整实战笔记。每个靶场均包含从边界突破到内网横向移动的全流程 WriteUp 及关键截图，旨在记录实战思路，沉淀内网渗透知识体系，并为安全爱好者提供可复现的参考路径。

---

## 笔记说明

每个子文件夹中包含且仅包含一个 ```WriteUP.md``` 文件以及若干图片。该文件即为最终笔记，是作者对通关靶场过程的详细记录与技术复盘。

同时，作者本人在做实验遇到的问题均已用 TIP 格式标注，欢迎各位读者提交遇到的其他笔记中未涉及的问题以及其对应的解决方案。
